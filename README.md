## ✨ Возможности

### 🎨 Редактор
- **Базовое**: яркость, контраст, экспозиция, насыщенность, резкость, оттенок (Hue)
- **Свет**: тени, света, S-кривая, тепло/холод
- **18 фильтров**: яркий, плёночный, ч/б, винтаж, кино, сепия, циан, fade, драма, ретро, закат, мята, розовый и др.
- **Кроп**: пресеты 1:1, 4:5, 3:2, 16:9, 9:16 + ручной с вводом координат
- **Геометрия**: поворот 90°, отражение по горизонтали/вертикали
- **Текст на фото**: 5 цветов, настраиваемый размер
- **Сравнение «до/после»**: удерживайте кнопку — видите оригинал
- **Undo/Redo** до 15 шагов

### 📦 Инструменты
- **Форматы**: PNG, JPEG, WebP
- **Качество**: ползунок 10–100 для JPEG/WebP
- **Размер**: пресеты 25/50/75/100% + ручной W×H
- **EXIF удаляется** — геопозиция, модель камеры, дата не сохраняются
- **Экспорт** в приватное хранилище или системную галерею (`Pictures/PhotoAI`)

### ✨ ИИ-редактор (в разработке)
Планируется: апскейл (Real-ESRGAN), восстановление лиц (GFPGAN), удаление фона (MODNet), колоризация (DDColor), состаривание (SAM). Все модели — локальные ONNX/MNN.

## 🔒 Безопасность и приватность

| Мера | Статус |
|---|---|
| Разрешение `INTERNET` | ❌ Не запрашивается |
| Аналитика, трекеры, реклама | ❌ Отсутствуют |
| Приватное хранилище | ✅ `app_storage_path()` |
| Google Backup | ❌ Отключён |
| EXIF в экспорте | ❌ Стирается |
| Сетевые запросы | ✅ Ноль |

Приложение физически не может отправить данные наружу — в `AndroidManifest.xml` нет разрешения `INTERNET`.

## 📱 Установка

1. Скачайте APK из [последнего релиза](../../releases/latest)
2. На телефоне: **Настройки → Безопасность → Установка из неизвестных источников** — разрешить для файлового менеджера
3. Откройте APK, установите
4. Запустите PhotoAI

**Требования**: Android 8.0+ (API 26+), ARM64.

## 🛠 Технический стек

| Компонент | Технология |
|---|---|
| UI | Kivy 2.2.1 |
| Сборка | Buildozer + python-for-android `v2023.09.16` |
| CI/CD | GitHub Actions |
| Шрифты | Inter (UI) + Material Symbols (иконки) |
| Изображения | Android BitmapFactory + Kivy CoreImage |
| Хранилище | SQLite + приватная папка приложения |
| Python | 3.10.11 |

**Без NumPy, Pillow, OpenCV** — всё сделано на стандартной библиотеке, Kivy и Android API через `pyjnius`. Это позволило обойти проблемы сборки и уменьшить APK.

Core:

image_utils.py — bytes ↔ Kivy Texture ↔ Bitmap
operations.py — LUT + циклы для эффектов

Локальная сборка APK не поддерживается из-за сложностей с Android SDK/NDK. Используйте git push — GitHub Actions соберёт APK автоматически.
